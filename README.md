# TurnOffScreen

一个极轻量（~31 KB、零依赖、绿色单文件）的 Windows **两段式智能息屏**托盘小工具，同时支持**外接 4K 显示器**与**笔记本自带屏幕**。

---

## 解决了什么痛点？

1. **没有一键关屏快捷键 / 够不到电源键**
   许多笔记本默认没有专门的 `Fn` 关屏键；外接显示器使用时笔记本常放在一旁，每次离开想快速黑屏非常不方便。
2. **4K 外接显示器真关屏后唤醒太慢（4～6 秒）**
   传统的硬件断信号息屏会让 4K HDMI/DP 显示器进入深度待机，哪怕只走开接杯水，回来动鼠标也要等显示器电源苏醒、扫信号源、重新完成 HDMI/HDCP 握手，干等五六秒非常割裂。
3. **短时间高频硬断电折腾硬件，不关又费电/伤屏**
   离开一两分钟就频繁硬断电，电源板和背光驱动反复冷热循环；反过来一直高亮停在静态画面既费电又消耗背光寿命（OLED 屏还有烧屏风险）。
4. **按显示器物理开关容易打乱多屏窗口布局**
   直接按显示器实体电源键常会触发 Windows 重新枚举显示器，导致桌面图标和窗口位置全乱。

---

## 两段式智能息屏方案

把**短时间离开**和**长时间离开**拆成两段，兼顾 **0.1 秒秒醒、保护屏幕、彻底省电**：

| 阶段 | 触发条件 | 行为 | 唤醒速度 |
| :--- | :--- | :--- | :--- |
| **第一阶段：极速黑屏** | 按 `Ctrl + Alt + B`（可自定义）或单击托盘图标 | 全屏纯黑置顶 + 隐藏鼠标 + **自动将外接屏（DDC/CI）与笔记本内屏（WMI）硬件背光压低至 `0%`**，不断开视频信号 | **< 0.1 秒瞬间秒亮**，自动还原原亮度 |
| **第二阶段：深度关屏** | 黑屏超过设定时间仍无人操作（默认 10 分钟，可自定义 5 分钟～24 小时） | 在黑屏掩护下先悄悄恢复原亮度值，再发送硬件断信号指令让显示器进入深度节能休眠 | 彻底断电省电，唤醒后亮度不丢失 |

> 午休或下班确定长时间离开时，也可以右键托盘图标直接点击 **「立即深度关屏（真断电）」**。

## 快速开始

1. 前往 [Releases](https://github.com/FeonzmEko/TurnOffScreen/releases) 下载最新版的 `TurnOffScreen.exe`。
2. 双击运行，任务栏右下角系统托盘会出现一个**红色电源小图标**。
3. 使用方式：
   - **键盘快捷键**：默认 **`Ctrl + Alt + B`** 立即进入极速黑屏，晃动鼠标或按任意键秒醒（若遇快捷键冲突会自动弹气泡提醒）。
   - **左键单击托盘图标**：立即进入极速黑屏。
   - **右键托盘图标**：
     - 立即进入极速黑屏 / 立即深度关屏（真断电）
     - 设置 **自动转深度关屏时间**（`5 / 10 / 15 / 30 / 60 / 120 / 180 分钟`、关闭、或 **自定义分钟数 1～1440**）
     - **修改快捷键...**：直接按键录制任意组合键，即时检测冲突并生效
     - 开关 **黑屏时自动压低显示器背光亮度**
   - **桌面快捷方式触发**：可创建指向 `TurnOffScreen.exe --trigger` 的快捷方式，双击即触发黑屏。
   - **开机自启**：按 `Win + R` 输入 `shell:startup` 回车，把 `TurnOffScreen.exe` 的快捷方式拖进去即可。

### 配置文件

设置会自动保存在 `%LOCALAPPDATA%\TurnOffScreen\config.txt`（支持手动编辑并热重载，无需重启）：

```ini
DeepSleepMinutes=60
DimHardwareBrightness=True
Hotkey=Ctrl+Alt+B
```

## 简要技术实现

- **零依赖单文件**：纯 C# 编写，直接通过 Windows 内置 `.NET Framework 4.x` (`csc.exe`) 编译为原生 WinExe，无黑框闪烁，常驻内存极低。
- **可自定义全局热键与多屏适配**：使用 Win32 `RegisterHotKey` 注册并动态检测热键冲突，开启 `Per-Monitor DPI V2` 感知确保 4K/多屏缩放下黑屏严丝合缝覆盖任务栏，通过 `GetLastInputInfo` 实现无全局钩子的低开销唤醒检测。
- **双路硬件调光**：外接显示器通过 `dxva2.dll`（DDC/CI），笔记本内置屏幕通过 WMI（`WmiMonitorBrightnessMethods`）实现硬件背光自动压低与恢复，并在断信号前自动归位原亮度防止醒来变暗。
- **硬件深度关屏**：通过 `SendMessageTimeout(HWND_BROADCAST, WM_SYSCOMMAND, SC_MONITORPOWER, 2)` 触发系统级息屏。
